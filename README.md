# Теплицы на Камчатке

Одностраничный сайт для бригады, которая продаёт, доставляет и устанавливает теплицы на Камчатке.

**[Открыть демо на GitHub Pages](https://ivan257257mrpi-cloud.github.io/teplicy-kamchatka/)**

- Адаптивная вёрстка, полноэкранный таймлапс, привязанный к прокрутке, и ручной выбор этапов.
- Каталог и форма, в которую автоматически подставляется выбранная теплица. В демо форма имитирует отправку в браузере.
- Сервер на Node.js и SQLite с очередью доставки. Поддерживает заявки с сайта и переписку между Авито и MAX.

## Локальный запуск

Установите Node.js 24 или новее. Проект использует встроенные HTTP и SQLite, поэтому устанавливать npm-зависимости не нужно.

```powershell
npm.cmd start
```

Откройте [локальный сайт](http://127.0.0.1:4173/). Форма сохраняет тестовое обращение в `data/greenhouse.sqlite` и показывает его номер. Для проверки сервера запустите `npm.cmd test`. В тестах используются временные базы и имитация ответов платформ.

Команда `npm run build:pages` собирает статическое демо в `dist/pages`. GitHub Actions прогоняет тесты и публикует сборку при обновлении ветки `main`.

## Подключение каналов

Для боевого запуска подготовьте домен, HTTPS на порту 443 и сервер с постоянным каталогом для SQLite. Запускайте один экземпляр сервера, делайте резервные копии базы и ограничьте частоту запросов к форме на обратном прокси. Перед публикацией замените заглушки, укажите сведения об операторе и добавьте утверждённую политику обработки данных.

1. Сделайте локальную копию `.env.example` под именем `.env`. Заполните ключи в настройках хостинга или в этом локальном файле. Храните его за пределами публичного каталога.
2. В Авито Pro проверьте доступ к API Messenger в профиле Алексея. Для собственной интеграции обратитесь в поддержку Авито. Укажите ID аккаунта, ключи и случайный URL-безопасный секрет webhook. Подпишите профиль на входящие сообщения по адресу `https://ВАШ-ДОМЕН/webhooks/avito/СЕКРЕТ`. Скрывайте этот путь в журналах прокси. Описание регистрации есть в [API Messenger Авито](https://www.avito.ru/developers/api-catalog/messenger/documentation).
3. Создайте бота на профиле ИП Алексея, пройдите модерацию и добавьте его администратором в закрытый чат бригады. Укажите токен бота, ID чата, ID трёх операторов и отдельный секрет webhook. [Создание бота в MAX](https://dev.max.ru/docs/chatbots/bots-create/create) · [ID чата](https://dev.max.ru/docs-api/use-cases/getting-chat-id)
4. В MAX зарегистрируйте `POST /subscriptions` с адресом `https://ВАШ-ДОМЕН/webhooks/max`, событиями `message_created` и `message_callback` и тем же секретом, что задан на сервере. Для запросов к API MAX настройте доверие сертификату Минцифры через `NODE_EXTRA_CA_CERTS`. Укажите его в окружении процесса до запуска Node.js. [Webhook MAX](https://dev.max.ru/docs-api/methods/POST/subscriptions)
5. Проверьте отправку заявки с сайта, получение сообщения по одному объявлению и ответ из MAX. Затем установите `AVITO_AUTO_REPLY=true`, если автоответ согласован. Приветствие отправляется при первом входящем сообщении, обработанном сервером для диалога.

Для ответа покупателю в MAX используйте действие «Ответить» на уведомлении бота. Введите текст и подтвердите его кнопкой «Отправить». Нажать её может автор черновика из списка операторов. При неопределённом результате отправки проверьте исходный диалог в Авито перед повтором.

Очередь повторяет временно неуспешную доставку сообщений в MAX. Неотправленные заявки остаются в базе. Для вложений Авито в MAX приходит текстовое уведомление о вложении.

## Изображения и ролик

Встроенный ImageGen создал для первого экрана фотореалистичную арочную теплицу на фоне камчатского вулкана. Для полноэкранного блока Seedance 2.0 Mini в Weave сгенерировала восьмисекундный таймлапс с двумя монтажниками и неподвижной камерой. Разметка, основание, каркас, покрытие и готовая теплица подписаны по ходу прокрутки. Вертикальная версия сохраняет всю ширину действия и заполняет экран размытым фоном ролика. При включённом уменьшенном движении этапы можно выбирать вручную по стоп-кадрам. Файлы `install-*.webp`, `install.mp4` и `install-portrait.mp4` находятся в `public/media`.
